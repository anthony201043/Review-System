# Review System

A Python program that collects customer reviews and ratings and calculates the average rating.

## Features

- Collects customer email addresses
- Collects customer reviews
- Accepts ratings from 1 to 5
- Validates rating input
- Processes review text
- Calculates the total rating
- Calculates the average rating
- Allows multiple reviews

- VS code
- Python
